# throttlepost-site

Public website for **ThrottlePost**, served with GitHub Pages at https://throttlepost.ca.

- `index.html`: landing page
- `privacy/index.html`: privacy policy, at https://throttlepost.ca/privacy/ (the URL used by the ThrottlePost Chrome extension and its Chrome Web Store listing)
- `CNAME`: custom domain for GitHub Pages (`throttlepost.ca`)

Plain static HTML: no build step, no scripts, no external assets. Contact: throttlepost@gmail.com
